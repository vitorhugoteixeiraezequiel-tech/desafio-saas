# Respondi

Olá! Sou o Vitor Hugo, e este é o meu projeto para o desafio.

## O que é

O Respondi é um sistema que ajuda empresas a responder clientes usando inteligência artificial.

A empresa cadastra as informações do negócio (horários, preços, entrega). Depois, cola a mensagem de um cliente, e a IA escreve a resposta pronta, usando só as informações cadastradas.

## O que tem no sistema

- Cadastro, login, edição e exclusão de usuário
- Painel de administrador para gerenciar todos os usuários
- Cadastro das informações do negócio
- Atendimento com IA: a IA identifica o tipo de mensagem e escreve a resposta
- Histórico de atendimentos

## Tecnologias

- Next.js e React
- TypeScript
- Tailwind CSS
- Google Gemini (IA)
- SQLite / Turso (banco de dados)
- Vercel (hospedagem)

## Como rodar

1. `npm install`
2. Copie o arquivo `.env.example` para `.env` e coloque a sua chave do Gemini
3. `npm run dev`
4. Abra http://localhost:3000
